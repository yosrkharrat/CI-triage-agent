# The fix plan, end to end on ci-triage-demo (25 Nov 2026)

The service ran locally in `auto` mode with `openrouter:google/gemini-3.5-flash`
for both the diagnosis and the plan; deliveries came from `scripts/relay_runs.py`;
Claude ran in the demo's fix workflow (claude-code-action, Claude subscription).
OpenRouter spend for the whole session, dry runs included: **$0.94**, under a $1
cap held by a watchdog that would have stopped the service at $0.95.

Hand-made cases on a small repo. It shows each path works, not how often.

## What the run found, and what changed

1. **A fresh database reused a fix branch name.** Branches were named after the
   row id, which restarts at 1, and `ci-triage/fix-1` already held the fix for
   #2 (PR #3). Housekeeping took the old branch for Claude's push and opened a
   draft PR from it (#7, closed); the fix workflow, which continues an existing
   branch, would have committed on top of it. The run was cancelled before it
   pushed. Branches are now named after GitHub's run id, and a delegation is
   refused when its branch already exists.
2. **The planner ran out of requests.** 14 was enough for the dry runs (7 to 10)
   and not for #6, which listed and read its way through the repository. The
   fallback held: the delegation went ahead with the plain brief. Now 24.
3. **The planner took sides it should not take** (found in the dry run, before
   the end-to-end): on #4 it planned to change an old test's expected value so
   a contradicting new test could pass, and on #5 to drop the snapshot fixture.
   Every mechanical check passed both. The prompt now names both cases; both
   then came out not feasible with the right blocker.

Also seen, not changed:

- Each `ci-triage plan` through OpenRouter exits 138: a bus error in garbage
  collection at interpreter shutdown, after all output is written. Not seen with
  Gemini direct, Groq or the test model, nor in the long-running service.
- OpenRouter bills the model's reasoning tokens, which pydantic-ai's usage does
  not count: about $0.04 per triage and $0.06 to $0.10 per plan, against ~20k
  and ~15k counted tokens.
- To trigger fresh runs, #6 and #5 got an empty commit. The triage reads the
  diff of the head commit only, so both trails say "asked for the diff: none
  available". The planner reads the diff of that commit too.
- The service was stopped before judging #10's CI, to stay under the cap. CI on
  the fix branch passed, and `guard()` on the compare API's diff passed, which
  is what the follow-up would have checked.

The demo PRs are left as they are: #6 and #8 open with their draft fixes #9 and
#10, #5 with its gave-up note.
